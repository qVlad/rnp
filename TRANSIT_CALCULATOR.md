# Калькулятор транзитной поставки WB — методика

**Маршрут:** [`/transit-calculator`](https://rnp.sellerfriends.ru/transit-calculator) · **Реализация:** TASK-LEAD-077 + TASK-LEAD-078 (auto-fill из ЛК WB) + TASK-LEAD-093 (wizard-mode)

Документ описывает что такое **транзитная поставка** в WB и как пользоваться
калькулятором. Сам калькулятор — frontend-only, формулы в коде
`frontend/src/pages/TransitCalculator.tsx:computeTransit`.

См. также: [`SUPPLY_CALCULATOR.md`](SUPPLY_CALCULATOR.md) (прямая поставка),
[`USER_GUIDE.md`](USER_GUIDE.md).

---

## 1. Что такое транзит и зачем

WB предлагает два типа поставки:

| Тип | Куда везёшь | Кто доставляет до конечного склада |
|---|---|---|
| **Прямая** | Сразу на конечный WB-склад (Коледино / Электросталь / …) | Никто — ты сам |
| **Транзит** | На транзитный **хаб** WB (Обухово / Шушары / Чашниково) | WB развозит сам по своей сети |

Транзит решает проблему «у меня товар в Москве, а конечный склад — Невинномысск».
Вместо аренды дальнобоя на 1500 км ты везёшь короб на ближайший хаб (50 км),
и WB сама раскидывает по карте. Платишь за этот сервис тариф `₽/л`.

**Когда выбирать транзит:**
- Дальние склады, до которых ты сам ехать не можешь.
- Объёмная партия, требующая полной фуры — на хаб довезти проще.
- Сезонный завоз с разлётом по 5+ складам в разные регионы.

**Когда выбирать прямую:**
- Локальные склады в радиусе 100-200 км — твоя логистика дешевле тарифа транзита.
- Маленькая партия (< 1500 л), для которой тариф `rate_small` будет дорогим.

## 2. Формула

```
total_volume = units × liters_per_unit
rate         = (rate_direct > 0)
                  ? rate_direct
                  : (total_volume < threshold ? rate_small : rate_large)
transit_cost = total_volume × rate
storage_cost = wb_tariff_box[final_warehouse].storage × units × storage_days
grand_total  = delivery_to_hub_total
             + delivery_to_hub_per_unit × units
             + transit_cost
             + storage_cost
```

Где:

- **`rate_direct`** — если в ЛК WB опубликован прямой тариф `₽/л` для пары
  «хаб → конечный_склад», используем его. Двухступенчатая шкала
  (`rate_small/large`) — fallback на случай когда точного значения нет.
- **`threshold`** — порог переключения, обычно 1500 л у WB.
- **`storage_*`** — берётся из таблицы `wb_tariff_box` (синкается из публичного
  WB Tariffs API каждый день в 08:00 MSK).
- **`delivery_to_hub_*`** — твоя внешняя логистика до хаба (подрядчик /
  собственный транспорт). WB её **не считает** — это твоя статья.

## 3. Откуда брать тариф

WB Tariffs API **не отдаёт** транзитные тарифы публично. Только в ЛК на
странице «Поставки и заказы → Поставки (FBW) → Транзитные направления».

Два пути ввести тариф:

1. **Auto-fill через расширение РНП** (рекомендуется). Если у тебя установлено
   Chrome-расширение (см. /settings → «Токены для Chrome-расширения») и ты
   зашёл в ЛК на страницу «Транзитные направления» — расширение сама
   подхватит тарифы и зашлёт на backend. После этого выбор пары
   «хаб → конечный_склад» в калькуляторе подставит тариф автоматически.
2. **Вручную.** Открой ЛК, найди пару, впиши `₽/л` в калькуляторе.

В шапке калькулятора зелёная плашка «📊 Тариф из ЛК WB · обновлён N дней
назад» — индикатор что auto-fill отработал. Можно править руками если хочешь
проверить «а что если тариф будет 3 ₽/л» — твои значения не перезапишутся,
пока не сменишь пару хаб+склад.

## 4. Режимы — wizard vs подробная форма

Toggle вверху страницы:

- **Подробная форма** (default) — все поля: SKU-picker + multi-warehouse
  compare (сравнить транзит на 5 разных конечных складов одним прогоном) +
  override прямой поставки + двухступенчатая шкала + compare с прямой
  поставкой.
- **Упрощённая (wizard)** — только основные поля: SKU → хаб → конечный склад
  → units → литры/шт → дней хранения → результат. Подходит для разовой
  задачи «посчитать стоимость одной партии».

Выбор персистится в localStorage (`transit.simple-mode.v1`), переключается
без потери введённых значений.

## 5. Что калькулятор НЕ считает

- **COGS товара** — себестоимость не входит, считаем только логистику +
  хранение. Если нужна полная экономика поставки → /unit-plan.
- **WB-комиссию при продаже** — это в /pnl, не в калькуляторе.
- **Acceptance fee на хабе** — обычно нулевая для транзита, но иногда WB
  включает платную приёмку. Если включена — добавь в `delivery_to_hub_total`.
- **Тип «Монопаллета»** — у WB своя формула `тариф × паллет`, не per-литр.
  Этот калькулятор для типа «Короб».

## 6. Сравнение с прямой поставкой (compare-блок)

В подробной форме калькулятор показывает таблицу:

| Тип | Логистика / транзит | Хранение | ИТОГО |
|---|---:|---:|---:|
| Прямая (тариф WB) | `acceptance` | `storage` | `=сумма` |
| Транзит — довоз до хаба | `delivery_to_hub_total` | — | `=delivery` |
| Транзит — хаб → склад (WB) | `transit_cost` | `storage` | `=сумма` |
| **Транзит — ИТОГО** | `delivery + transit` | `storage` | `=сумма` |
| **Δ (транзит − прямая)** | | | разница |

Если транзит дороже прямой по тарифам WB — это нормально. Транзит выгоден
если **твоя внешняя логистика** до хаба сильно дешевле чем до конечного
склада. Например: довезти короб на Обухово из Москвы — 5000 ₽, до
Невинномысска — 25000 ₽.

## 7. Multi-warehouse compare (подробная форма)

Можно добавить до 5 дополнительных конечных складов и сравнить стоимость
довоза на каждый. Тариф транзита берётся per-pair из ЛК WB (если есть в
базе), иначе fallback на общий manual-тариф. Подсвечивается минимум зелёным.

## 8. Stale-tariff banner

С 1 апреля 2026 WB поднял тарифы транзита в среднем на ~20%. Тарифы из ЛК
синхронизированы через расширение РНП ad-hoc (при заходе на страницу), не
по расписанию. Если `synced_at` старше 30 дней — будет жёлтая плашка
«⚠ Тариф давно не обновлялся, проверь в ЛК» (TASK-LEAD-094).

## 9. Edge cases

- **Двухступенчатая шкала и `rate_direct`** — если `rate_direct > 0`,
  двухступенчатая шкала игнорируется (поле перетекает в opacity-50). Это
  чтобы не путать «у меня есть точное значение» и «у меня только примерное».
- **Пара хаб+склад без тарифа** — оранжевая плашка «🔄 Не нашли тариф»;
  калькулятор использует ручные значения `rate_small/rate_large`.
- **Сменил пару хаб+склад** — manual-флаги сбрасываются, новый auto-fill
  подставит силно (без confirm). Это чтобы каждая новая пара
  отрабатывалась с чистого листа.
- **Конфликт ручного и auto-fill значения** — показывается Dialog «📊 Тариф
  обновлён в ЛК WB. Применить новые значения?» (TASK-LEAD-090).

## 10. Где лежит код

- Frontend — `frontend/src/pages/TransitCalculator.tsx` (~1700 строк,

  POST upload от расширения).
- Модель — `WbTransitTariff` (миграция 0059) с UNIQUE `(tenant, hub, dest)`.
- Extension — `extension/src/content/wb-transit-tariffs-*.ts` (MAIN+ISOLATED
  content scripts с FNV-1a дедупом).
