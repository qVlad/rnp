## 1. Карта модулей TrueStats (свежий просмотр после P1+P2)

TrueStats — петербургская компания, статус «проверенный сервис от ВБ». Стек заявлен PHP/Symfony+PostgreSQL+Redis+RabbitMQ; фронт React+TypeScript+Tailwind+Vite. Поддержка WB + Ozon + **Яндекс.Маркет** (запущен в 2026, в апреле вышел из бесплатного теста). 6 основных модулей.

### 1.1 Модули

| Модуль | Описание | Уникальность | Где у нас |
|---|---|---|---|
| **Оцифровка** (Dashboard) | KPI: маржа, оборачиваемость, выкуп, ДРР, +50 метрик. Сравнение периодов любых, drill по магазин/бренд/артикул/размер | **Custom-метрики через формулу** — пользователь сам собирает показатель из других. Это уникально и у нас этого нет | `Dashboard.tsx` + 16 KPI, **нет custom-формул** |
| **РНП «Рука на пульсе»** | Ежедневный operational-контроль. Динамика заказов/продаж/рекламы по дням. Прогноз прибыли «до выкупа», контроль ДРР per-карточка | Бренд-имя совпадает с нашим (!) Сам модуль = ежедневная динамика по карточкам с алертами | У нас сам сервис так и зовётся. Динамика — есть. Per-карточка drill — частично (Units, Brands) |
| **Аналитика рекламных кампаний** | Кампания → выручка/прибыль/ДРР. Heatmap по дням и метрикам. Сравнение кампаний side-by-side. Метрики: **CPL, CPS, basket-conv, order-conv** | Связка реклама ↔ прибыль per-кампания; conversion-метрики | Heatmap ✅. Per-кампания ↔ прибыль — частично (`unit_economics`). Basket-conv нет |
| **Финансы** (ДДС + Платёжный календарь) | Поступления/списания по счетам и категориям. Календарь будущих платежей. **«Маркер Сегодня»** на ленте операций. Кассовые разрывы — прогноз | Многокабинетный учёт нерыночных расходов, разделение по операциям/счетам/контрагентам | ДДС ✅ (`opex`, `cash-flow`), календарь ✅, **счета/контрагенты только частично** (поле `contractor` в opex_entries) |
| **План-Факт** | План на выручку/продажи/маржу/ROI/ДРР/расходы по артикулам. **Импорт Excel плана** (артикул+баркод+размер+показатели через спецключи). Распределение: равными долями / пропорционально показателю прошлого периода | Импорт плана из Excel; авто-распределение по динамике; прогресс-бары на дашборде | План ✅ (`sales_plans` 3 scope). Импорт Excel — частично (`excel_io`). Пропорциональное распределение — нет |
| **Склад** | Остатки + в пути + поступления/перемещения/списания. Себестоимость, **капитализация**, планирование поставок | «Капитализация» = денежная сумма на складе как актив. Многоскладской учёт перемещений | Остатки + supplies + COGS ✅. **Капитализации как отдельный отчёт нет**. Off-platform movements ✅ |

### 1.2 Дополнительные фичи (из Telegram-канала, выпущены за последние 2-3 месяца)

| Фича | Что | Уникальность |
|---|---|---|
| **Custom-метрики через формулу** | Пользователь создаёт свою KPI: «(выручка − реклама) / заказы». Видна на дашборде и в виджетах | Высокая. У нас всё хардкод |
| **Кросс-маркетплейс дашборд** | WB + Ozon + ЯМ в одном представлении, сравнение по маркетплейсам | У нас только WB |
| **Кросс-секционные комментарии** | Пометка на артикуле/неделе/кампании видна везде (Оцифровка/РНП/Реклама) | Низкая, но удобно |
| **«Склейки» (бандлы)** | Группа артикулов как один товар, карусель в карточке | Группы у нас есть (`product_groups`), но без карусели и без UX «бандл» |
| **Экспорт РНП прямо из таблиц** | Скачать CSV/XLSX любой таблицы | Частично — Excel I/O есть, но не из любой таблицы |
| **Гибкое сравнение периодов** | Любые 2 периода с любым интервалом | У нас только период vs предыдущий равный |
| **Маркер «Сегодня» в ДДС** | Визуальная риска в ленте операций между past/future | Нет |
| **Команда без лимитов** | Сколько угодно юзеров, гранулярные права (можно открыть партнёру только результаты, скрыть OPEX) | У нас 3 роли, brand-RBAC — близко, но не «гранулярно по разделам» |
| **Бесплатный Telegram-бот еженедельных отчётов с кастомными метриками** | Юзер выбирает метрики → бот шлёт по расписанию | У нас бот есть, но с фиксированным набором |
| **Мобильное приложение** | Анонсировано в Telegram, iOS/Android | Веб-only |
| **Распределение OPEX на несколько артикулов/брендов/аккаунтов** | Один расход → разнесли пропорционально | У нас один OPEX = одна категория. Распределения нет |
| **«Маржа без операционных расходов»** | Отдельный KPI = валовая маржа (revenue − COGS − WB-удержания − реклама) | У нас в P&L есть строка contribution margin, как KPI на дашборде — отсутствует |
| **3-дневный триал за 1 ₽** + промокоды (7PLUS = 14 дней за 1 ₽) | Лидген-крючок | У нас нет триала, только бесплатный signup |

### 1.4 Налоги (важно — слабое место TrueStats)

В docs указано 5 режимов: УСН Доходы / УСН Доходы-Расходы +фикс.НДС / УСН Доходы-Расходы +НДС 22% / ИП ОСНО / ООО ОСНО + АУСН (8% / 20%).

**Но в документации прямо сказано: «TrueStats — не бухгалтерский сервис», полноценного налогового отчёта НЕТ.** Только справочная ставка для уменьшения чистой прибыли в P&L. Никакой методики Стаса, КУДиР, Уведомлений о выкупе, per-regime exclusion, ничего этого нет. Это **наш моат**.

## 5. Стратегические рекомендации

### Скопировать в ближайший месяц (3)

1. **Custom-метрики через формулу** (P0 — нет аналитики XXI века без этого)
   - `metric_templates` таблица (name, formula, format, owner_user_id, scope)
   - `simpleeval` или `asteval` для безопасной evaluation (whitelisting символов)
   - UI: формочка «новая метрика» → выпадающий список доступных полей → preview на текущем периоде → сохранить
   - Регистрация в Dashboard / Units / P&L как доп.колонка / KPI

2. **Триал-механика + промокоды**
   - `trial_until` поле в `tenants`, дефолт +14 дней при signup
   - `promo_codes` таблица + flow при signup
   - Banner «Триал заканчивается через N дней» на /dashboard
   - Технически 1 день работы. Бизнесово — критический рычаг конверсии

3. **Капитализация склада + кросс-секционная страница «Склад»**
   - Снимок (текущие остатки × COGS) на любую дату
   - Динамика капитализации помесячно — график
   - Sub-page внутри `/units` или новая `/inventory`: остатки + в пути + поступления + перемещения + капитализация в одной точке
   - Это объединит наши уже существующие данные (stocks, supplies, off_platform_movements, cogs_weighted) в один отчёт

### НЕ копировать (2)

1. **Кросс-маркетплейс дашборд + ЯМ интеграция**
   - Ozon — да, через 1 квартал (отдельный roadmap-документ нужен)
   - ЯМ — нет: рынок мал, ROI инвестиции в интеграцию низкий, всегда можно «когда станет нужно»
   - Тратить ресурс на «3 МП в одном окне» — увод от нашего сильного фланга (tax + reconciliation)

2. **Мобильное приложение**
   - Наш сегмент — финдиректор/собственник за рабочей станцией
   - PWA в 10 раз дешевле и закрывает 80% потребности (открывается в Safari как app, push через web-push API)
   - Скоро можно сделать `manifest.json` + service-worker — это XS, не XL

### Один ход чтобы обойти (не имитация)

**«Сравнение копейка-в-копейку с бухгалтером + кабинетом WB одновременно».**

TrueStats честно говорит «не бух-сервис». У нас уже:
- Δ=0₽ с ЛК WB (reconciliation wizard)
- Δ=0₽ с расчётом бухгалтера (АУСН/УСН-методика Стаса)

**Нужно добавить один экран «Аудит-режим»:**
- Слева — наш P&L
- Посередине — WB-кабинет (через docs-API parsing или manual import XLSX-выгрузки ЛК)
- Справа — XLSX бухгалтера (parsed мап-колонок)
- Подсветка строк с Δ > 0,01 ₽ + дроп-даун «принять WB / принять наш / принять бухгалтера»

Эту нишу не закрывает ни TrueStats, ни Eggheads, ни MPStats. Маркетинговый посыл: «Единственный сервис, где собственник, бухгалтер и WB сходятся копейка-в-копейку».

  - Migration 0034: `opex_entry_allocations(opex_id, scope_type ENUM('nm','brand','group','tenant'), scope_value TEXT, weight DECIMAL)`

## 8. Лидген-крючки против TrueStats

TrueStats берёт трафик через:
- 3 дня за 1 ₽ — низкий барьер
- 15-20% партнёрки — мотивированные блогеры
- YouTube-канал (43-мин обзор сервиса с таймкодами)
- «Проверенный сервис ВБ» бейдж
- Telegram-канал @truestatsapp

Что мы можем сделать дополнительно:

1. **Бесплатный калькулятор АУСН/УСН** standalone — публичная страница без регистрации: ввёл оборот за месяц → получил расчёт АУСН 8% или УСН 6% + сравнение режимов. CTA: «Сохранить → зарегистрироваться → автоматический расчёт каждый месяц».

2. **Бесплатный калькулятор новинок CIF (Китай)** — наш `/new-products` сделать публичным с water-mark «сохрани историю — зарегистрируйся». Эта фича у TS отсутствует.

3. **Лендинг «Аудит-режим»** — отдельная страница с маркетингом «единственный сервис где WB + бухгалтер + ваши цифры сходятся копейка-в-копейку», демо-видео, CTA на триал.

4. **«Сверка с ЛК WB Δ 0%» как USP** — выложить публично примеры reconciliation-отчётов (анонимизированные), показать ровно 0,00 ₽ дельту на закрытых неделях.
