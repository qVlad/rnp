**Дата открытия файла:** 2026-05-20

> Перед каждой задачей — прочитай `agents/RULES.md`, `agents/release-manager.md`,
> `DEPLOY_LOCK.md`, релевантные секции `CLAUDE.md` (§«документация + версия +
> деплой» + §«deploy lock»).

## Что сюда попадает

1. **Hotfix / нерегулярные релизы** — отдельная запись `RELEASE-NNN` с
   обоснованием и составом (какие TASK-DEV/BUG-DEV входят).
2. **Catch-up / skew-fix** — когда версии разъехались между тремя файлами,
   и нужен релиз-выравниватель.
3. **Process changes** — улучшение release-flow (автоматизация bump'а через
   скрипт, добавление CHANGELOG.md, интеграция с GitHub Releases, и т.д.).
4. **Постмортемы failed-релизов** — что упало, что починили, какой урок
   зафиксировали.

## Что сюда НЕ попадает

- Рутинные «одна фича — один минор-bump → деплой». Координация для них
  идёт через `DEPLOY_LOCK.md` (журнал внизу) и запись в исходном
  `tasks-<role>.md`. Создавать `RELEASE-NNN` на каждый чих — избыточно.
- Code-review / архитектура — это Lead.
- Feedback после релиза — это QA + персоны + Analyst (Правило 2.5).

## Формат / Жизненный цикл

См. `RULES.md` §«Формат задачи». Префикс — `RELEASE-NNN`. Шаблон:

```markdown
### RELEASE-NNN: Краткое название

- **Исполнитель:** Release Manager
- **Приоритет:** P0 / P1 / P2
- **Оценка:** Xч (обычно 5-30мин на сам деплой + время на pre/post)
- **Состав релиза:**
  - TASK-DEV-NNN: ...
  - BUG-DEV-NNN: ...
- **Тип bump'а:** patch / minor / major (с обоснованием по SemVer)
- **Версии:** X.Y.Z → X.Y.(Z+1)
- **Pre-flight чеклист:**
  - [ ] `DEPLOY_LOCK.md` = 🟢 Свободно
  - [ ] Все TASK/BUG в составе — `Выполнено` / `Исправлено`
  - [ ] Локальный `tsc --noEmit` зелёный (если есть frontend)
  - [ ] Локальный `python3 -c "import ast..."` зелёный (если есть backend)
- **Критерии готовности:**
  - [ ] Замок поставлен (chore(deploy): lock — vX.Y.Z)
  - [ ] 3 файла версий бампнуты на X.Y.Z
  - [ ] Commit + push в qVlad/rnp main
  - [ ] `./scripts/remote.sh deploy` прошёл успешно
  - [ ] Smoke на проде: `/api/version` отдаёт X.Y.Z
  - [ ] Замок снят (chore(deploy): unlock — vX.Y.Z OK)
  - [ ] Строка в журнале `DEPLOY_LOCK.md`
- **Статус:** Открыта
```
