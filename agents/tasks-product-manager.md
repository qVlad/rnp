## Backlog

### TASK-PM-001: Первый grooming `tasks-lead.md` (1240+ строк → top-10 sprint + stale-cleanup)

- **Исполнитель:** PM
- **Приоритет:** P1 (организационный долг — без grooming'а priority-сигнал теряется в шуме)
- **Оценка:** 2-3ч
- **Описание:** Первый sweep свежевведённой PM-роли. Пройти по всем открытым `TASK-LEAD-NNN` (примерно 30+ записей в `tasks-lead.md`), для каждой:
  1. Жив ли scope (актуален ли запрос, не решён ли побочно)
  2. Приоритет (P0/P1/P2) — переутвердить или скорректировать
  3. Stale (>3 мес без активности и не P0) — закрыть как `Снято: stale, YYYY-MM-DD, PM-NNN`
  4. Active sprint (top-10 P0/P1) — pin в начало файла как отдельная секция
- **Критерии готовности:**
  - [ ] Прочитан весь `tasks-lead.md`
  - [ ] Каждая открытая TASK-LEAD имеет актуальный priority-tag
  - [ ] Stale-задачи закрыты с обоснованием
  - [ ] «Active sprint» секция в начале `tasks-lead.md` (top-10 на текущий период)
- **Зависимости:** TASK-LEAD-037 (этот реструктур) — закрывается до этой задачи, чтобы PM-роль существовала
- **Статус:** Открыта
