## TL;DR

**Мы УЖЕ replacement для WB-only клиента** — 5 из 6 модулей TrueStats покрыты
полностью или лучше (см. §1), плюс есть три моата которых у TS нет (налоги,
4-way Reconciliation, UNIT-план).

**Незакрыто 1 техническая фича** из Sprint+3 (OPEX many-to-many, P2) — её
можно делать или нет, в зависимости от того насколько важна для целевого
клиента.

**Реальные блокеры замены для пользователя** — НЕ технические:
1. Нет публичного pricing + signup без друга-владельца (бизнес-вопрос)

3. Нет публичного маркетингового сайта

Если решить эти 3 — техническая часть «минимальной замены» закрыта.
Если оставить как есть — РНП ≈ TrueStats по фичам, но недоступен новым клиентам.

| **WB Documents API** (Уведомления о выкупе + Акты взаимозачёта) | `integrations/wb/documents.py`, миграции 0019/0021 | +330k ₽ за 4 мес дополнительного дохода. У TS публично нет |

**Сильная позиция:** 8 моатов. Из них **tax + reconciliation + UNIT-план** —

## 4. Минимальная замена TS — определение по сегментам

### 4.1. Для кого мы УЖЕ полная замена (без доработок)

**Целевой клиент A: WB-only селлер с оборотом 1.5-30М/мес, штатный бухгалтер.**

Этому клиенту мы перекрываем TS на 100% по фичам **прямо сейчас**, плюс
даём tax-моат и Reconciliation которых у TS нет. Никаких доработок не нужно.

Что они получат лучше чем у TS:
- Δ=0₽ налоговые отчёты для бухгалтера (TS — «не бух-сервис»)
- 4-way Reconciliation как USP — «здесь сходятся ваши, WB и бухгалтер»
- UNIT-план для планирования закупок Excel-методики 1:1
- Brand-scoped manager view + plan edit requests workflow

Что они получат сопоставимо с TS:
- Dashboard + 16 KPI + custom-метрики
- AdsHeatmap + conversion-метрики
- ДДС + платёжный календарь
- План-факт с импортом XLSX
- Капитализация склада + UNIT-план

**Цена замены для этого сегмента = 0 разработческих часов.**
**Цена = чистый product-marketing работа.**

### 4.2. Для кого мы НЕ полная замена

**Клиент B: WB + Ozon + ЯМ мульти-маркетплейс.** Не наш ICP, требует Ozon
integration → отказ (см. §3.2).

**Клиент C: WB-агентство с 10+ кабинетами клиентов.** Multi-cabinet workspace
нужно. Тоже не наш ICP.

**Клиент D: Бизнес с распределённым OPEX (1 OPEX → 3+ бренда).** Сейчас
теряет точность в P&L per-brand. **Лечится TASK-LEAD-030**.
