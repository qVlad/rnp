## Доступ к TrueStats API (важно)

- Основной `api.truestats.ru` и `api3` — **мертвы/блокируют** датацентровый IP хоста.
- **Рабочий хост: `api2.truestats.ru`** (его использует зеркало). С хоста доступен.
- Фронт-зеркало: **`https://mirror-app.truestats.ru`** (когда `app.truestats.ru` лежит).
- Авторизация: заголовок `x-auth-token` (хранится в localStorage фронта, 120-hex).
  Креды для логина в зеркало: `altecomllc@yandex.ru` / `p3v-g46-4dD-Tgd`.
- Кабинет **Onyx = account id 25143**. Фильтр в теле: `filters:{accounts:[25143]}`.
- Ключевые эндпоинты:
  - `POST /reporting/main/stats` — плитки Оцифровки/Сводного (realisation, sales,
    toTransfer, commission, acquiring, logistics, storage, tax, taxBase,
    wbFinalReward, profit, profitWithoutExpense, advertisingExpenseSum, expense …).
  - `POST /reporting/main/products` — per-SKU (article, realisation, sales,
    cost, costOfSales, totalSales, profit, expense, advertisingExpenseSum …).
  - `POST /reporting/facets` — справочник accounts/brands/categories.
  - `POST /v1/operation/list` — реестр финопераций (доходы/расходы, OPEX).
  - `POST /v1/operation/filter-values`, `GET /v1/operation/bill/balance`.
  - `POST /v1/cashflow/payment-calendar` — ДДС/платёжный календарь.
  - `POST /plan-fact/list` — План-факт.

## Заказы / Прочие удержания / Прибыль — сверка 18-24.05 (v0.64.7, DEV-058)
- **Заказы (RCA «неполные заказы»):** причина — НЕ WB rate-limit, а логика
  `metrics._funnel_covers_period()`: возвращала True по «есть хоть одна строка
  funnel». Funnel (Analytics API) синкается ~14 дней назад → для 18-24.05 были
  только 22-24 → funnel-сумма заказов = 314 вместо 871. Фикс: требуем покрытие
  **каждого дня** периода; иначе fallback на полный `wb_orders` (Statistics API).
  Чинит и Дашборд (та же функция). Остаток 813 (наш wb_orders) vs 871 (TS) =
  рассрочка/installments — есть только в Воронке, за старые недели недоступна.
- **Прочие удержания:** TS otherDeduction (22 990) = deduction + приёмка − доплаты,
  БЕЗ штрафов. Наш scope раньше включал penalty (→29 892). Фикс: penalty вынесен
  отдельно («Штрафы», 6 902). `/api/deductions` отдаёт `total` (без штрафов) +
  `fines_total`. 22 990 = TS копейка-в-копейку.
- **Прибыль:** TS вычитает «Прочие удержания» (операционные, без штрафов) из
  прибыли. Фикс: `/summary-report` profit −= prochie (аллокация по SKU как OPEX).
  18-24: 504 083 − 22 990 = 481 093 ≈ TS 482 206 (Δ1113 = реклама 806 + налог 307).
  Штрафы в прибыль НЕ входят (отдельно) — как TS.

## Sync-надёжность (WB rate-limit)
- WB агрессивно режет этого продавца (429 «Limited by global limiter»). Из-за этого:
  - Реклама — был wipe-баг (delete весь диапазон → потеря при 429). **Починено.**
  - Склады — синк защищён (early-return при пустом fetch, без delete), НЕ теряет
    данные, но застаивается пока WB throttle. Самовосстанавливается (manual refresh
    сработал → 05.06). Код-фикс не нужен; нужен мониторинг свежести.
  - Заказы — funnel неполнота больше НЕ роняет цифру (fallback на wb_orders).
