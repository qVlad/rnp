# Конкурентный анализ: РНП vs Evirma

> Дата составления: 2026-05-17. Источники: evirma.ru (главная + /my), chrome.evirma.ru (лендинг расширения), Chrome Web Store страница расширения, обзор на stats-mp.ru, Telegram-канал @maxprowb, отзывы в Chrome Web Store, упоминания в Telegram @wbsharks, отдельные статьи vc.ru об альтернативах.
>
> **Confidence: low-to-medium.** Расширение не ставили в браузер и сами не щупали, в платный тариф (990 ₽) не заходили — поэтому конкретика по «автобиддеру», «отчёту по выкупам по регионам», «частотности кластеров за 30/365 дней» — по описаниям и обзорам. Из публичного: главный лендинг очень тонкий, основной маркетинг идёт через расширение + Telegram. Тарифной матрицы публично нет — только «от 990 ₽/мес» из обзоров.

---

## 0. Главное в одной строке

Evirma — **браузерное расширение** (Chrome MV3, ~100k установок, рейтинг 4.2-4.5/5), которое показывает **overlay поверх wildberries.ru с реальными CPM-ставками, частотностью запросов, приоритетом складов, позициями карточек**. Спонсируется банком Точка, базовая аналитика — бесплатная, paid-тариф от 990 ₽/мес добавляет автобиддер (5 РК) и снимает лимиты.

**Это другой формат продукта**, чем у нас. Они — chrome-overlay для seller-marketer'а на стороне WB. Мы — server-side SaaS с финансовой аналитикой и tax-фронтом. Прямой конкуренции нет, но есть **3 идеи которые стоит украсть**, и есть **1 формат-крючок (бесплатное расширение для лидгена)** который стоит обсудить отдельно.

## 1. Карта модулей Evirma

### 1.1 Overlay на страницах WB (это их core-продукт)

| Где | Что показывает |
|---|---|
| Каталог / категории | реальный CPM каждой рекламной карточки, признак «реклама/органика», частотность запроса (за 30/365 дней), приоритет категории, СПП |
| Поисковая выдача | весь аукцион — CPM по каждому месту, доставка склада, позиция (рекламная / органическая), показ кластера запросов с общей частотностью |
| Карточка товара (PDP) | бренд, рейтинг, цена, CPM в рекламе по карточке, скорость доставки приоритетного склада |
| Рекламный кабинет WB | улучшенная статистика РК: показы, клики, CTR, расход, добавления в корзину, заказы, CPA. Аналитика по ключевым фразам с возможностью «в минус-фразы одним кликом» |
| Аналитика SEO/keyword | кластеризатор запросов: одна фраза-головка кластера = карточка получает показы по всем подзапросам; экспорт релевантных ключей в Excel |
| По карточке поверх времени | «оценка изменений карточки на конверсию» — фиксирует изменение фото/текста/цены и сравнивает конверсии до/после |

### 1.2 Аналитика складов и регионов

| Фича | Описание |
|---|---|
| Приоритет складов | для каждого запроса/региона показывает какой склад WB сейчас приоритетный |
| Скорость доставки приоритетного склада vs «вашего» | помогает выбрать куда отгружать |
| Позиции карточки по регионам | в каких регионах вы в топе, в каких выпали |

### 1.3 Автобиддер (paid)

| Фича | Описание |
|---|---|
| Автоматическое управление ставками | держит карточку выше конкурента «+1₽/клик» (простой алгоритм, не ML) |
| Лимит на тарифе Базовый | 5 РК за 990 ₽/мес |
| Более старшие тарифы | в публичных источниках не описаны — нужно регистрироваться |

### 1.4 Web-кабинет (evirma.ru/my)

Минимальный. Сводится к: вход, привязка WB-токена, настройка автобиддера. Полноценной P&L / unit-аналитики в web-кабинете нет — основной интерфейс это расширение поверх WB.

### 1.5 Тарифы (что нашлось публично)

| Тариф | Цена | Что входит |
|---|---|---|
| Free (расширение) | 0 ₽ | overlay со ставками, частотность, кластеризатор (с дневными лимитами просмотров), приоритет складов, статистика РК. Большая часть продукта |
| Базовый | 990 ₽/мес | unlimited overlay + автобиддер для 5 РК |
| Старшие | публично нет | предположительно больше РК у биддера, расширенная история |

Промо: 9 дней бесплатно любой тариф по реф-ссылке.

### 1.6 Технически

- Chrome MV3 расширение. Около 100k пользователей.
- Берёт публичные данные WB через катало­говые/поисковые endpoint'ы (search-by-text, card-detail, по которым ходит фронт wildberries.ru) + рекламные ставки из публичного `auction` endpoint.
- Личные данные продавца (расход РК, ключевые фразы кампаний) — подтягиваются после привязки WB-токена и проксируются через бэкенд Evirma.
- Риск бана от WB: low — overlay не делает «своих» запросов мимо токена, частоту запросов ограничивает на клиентской стороне (это, в принципе, такой же трафик как у браузера).
- Известные проблемы из отзывов: нестабильность после обновлений WB-фронта, замедление загрузки страниц, иногда «белый экран», задержка данных частотности.

### 5.2 Стоит ли делать своё расширение?

**Короткий ответ: нет, не сейчас. Возможно — узко-целевое позже.**

Аргументы ПРОТИВ полноценного расширения уровня Evirma:
- Их продукт развивается годами, ~100k юзеров, специализированная команда на reverse-engineering фронта WB.
- WB постоянно меняет вёрстку и API публичных endpoint'ов — расширение требует регулярного patching'а (это видно по отзывам: «после обновления WB сломалось»).
- Не наша единица анализа (мы — кабинет селлера, а не каталог покупателя).
- Цена: команда минимум 1 frontend-инженер full-time только на поддержание поверх WB-фронта.

Аргументы ЗА мини-расширение **как лидген-крючок** (узкая ниша):
- Eggheads тоже использует расширение как лидген (см. COMPETITIVE_EGGHEADS.md §7), и у нас в том плане это пункт Sprint 4+.
- Наш USP в расширении мог бы быть НЕ overlay-аукцион (там нас сожрут Evirma и Анабар), а **финансовый ярлык поверх своих карточек**: «эта карточка приносит маржу X₽, ROI Y%, налог Z₽».
- Это уникально: ни Evirma, ни Анабар не показывают **управленческий результат** на карточке.

**Рекомендация:** не делать полноценное расширение в ближайшие 2-3 спринта. Если делать когда-то — то с одной целью: показать на странице карточки в WB-кабинете selller'а наши унит-метрики (маржа, ROI, налог, дни до stockout). Маленькое, узкое, не пытающееся конкурировать на overlay-территории.

| Фича | Что даёт | Сложность | Эффект |
|---|---|---|---|

## 7. Тарифная гипотеза (apдейт)

Evirma — **бесплатное расширение + 990 ₽/мес за биддер**. Это другая модель, чем Eggheads (25k вход) или мы (план был 7-12k base / 25-35k pro в Eggheads-roadmap).

Что важно для нашего тарифа:

- **990 ₽/мес — не точка сравнения с нами.** Evirma за эти деньги даёт автобиддер, не tax-отчёт. Мы не конкурируем по цене с расширением.
- **100k бесплатных юзеров Evirma — потенциальный рынок для нас.** Они уже привыкли «есть расширение + есть личный кабинет». Эти юзеры — selller'ы 1-30 млн ₽/мес, которым нужна финансовая часть, но не нужна вторая аналитика по рекламе.
- **Не позиционироваться как «дешёвая альтернатива Evirma»** — мы не альтернатива, мы **дополнение**. Сообщение для маркетинга: «оставайтесь на Evirma для рекламы, возьмите РНП для финансов и бухгалтерии». Cross-sell, не replace.
